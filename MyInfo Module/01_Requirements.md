# My Info Module – Requirements

## 1. Module Overview

The My Info module allows employees to view and manage their personal,
contact, employment, and other employee-related information.

## 2. Objective

The objective of testing the My Info module is to verify that employees
can correctly view, update, and manage their permitted personal and
employment information.

## 3. Functional Requirements

### FR-MYINFO-001 – My Info Navigation

The system shall allow an authorized employee to open the My Info module.

### FR-MYINFO-002 – Personal Details

The system shall display the employee's personal information.

### FR-MYINFO-003 – Edit Personal Details

The system shall allow employees to update permitted personal information.

### FR-MYINFO-004 – Employee ID

The system shall display the employee ID correctly.

### FR-MYINFO-005 – Employee Name

The system shall display the employee's first, middle, and last name
where applicable.

### FR-MYINFO-006 – Nickname

The system shall allow the employee to update the nickname where permitted.

### FR-MYINFO-007 – Date of Birth

The system shall display and validate the date of birth.

### FR-MYINFO-008 – Gender

The system shall allow the employee to select or update gender where permitted.

### FR-MYINFO-009 – Nationality

The system shall allow the employee to select nationality where applicable.

### FR-MYINFO-010 – Contact Details

The system shall allow employees to view and update permitted contact
information.

### FR-MYINFO-011 – Address

The system shall allow employees to view and update address information.

### FR-MYINFO-012 – Emergency Contacts

The system shall allow employees to manage emergency contact information
where permitted.

### FR-MYINFO-013 – Dependents

The system shall allow employees to manage dependent information where
permitted.

### FR-MYINFO-014 – Immigration Details

The system shall allow authorized employees to view or manage immigration
information where applicable.

### FR-MYINFO-015 – Job Details

The system shall display the employee's job-related information.

### FR-MYINFO-016 – Save Information

The system shall save valid changes successfully.

### FR-MYINFO-017 – Validation

The system shall validate required fields and invalid information.

### FR-MYINFO-018 – Authorization

Employees shall only be able to modify information for which they have
permission.

### FR-MYINFO-019 – Data Persistence

Updated employee information shall remain available after page refresh
or re-login.

## 4. Non-Functional Requirements

### NFR-MYINFO-001 – Usability

The My Info module should be easy to navigate and understand.

### NFR-MYINFO-002 – Performance

My Info pages and save operations should respond within an acceptable time.

### NFR-MYINFO-003 – Security

Employee information should only be accessible to authorized users.

### NFR-MYINFO-004 – Compatibility

The module should work correctly on supported browsers.

### NFR-MYINFO-005 – Reliability

Employee information should be stored and retrieved reliably.

## 5. Testing Scope

Testing will cover:

- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing
- UI Testing
- Workflow Testing
- CRUD Testing
- Authorization Testing
- Security Testing
- Compatibility Testing
- Performance Testing
- Exploratory Testing
- Regression Testing
- Smoke Testing
- Sanity Testing
